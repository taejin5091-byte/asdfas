01 / 오늘의 결과

버튼 한 번으로 신호와 소리를 순서대로 제어하기

최종 목표는 초록불로 대기하다가 버튼을 누르면 다음 순서를 한 번 실행하고 초록불로 돌아오는 것입니다.

초록불 유지버튼 입력 대기
노란불 1초소리 없음
빨간불 15초멜로디 재생
노란불 1초소리 꺼짐
초록불 복귀다음 입력 대기

오늘 확인한 내용

  • 세 LED는 HIGH일 때 켜집니다.
  • 버튼을 누르면 신호 순서가 실행됩니다.
  • 색상과 핀 번호를 실제 배선에 맞추자 정상 동작했습니다.
  • 최종 배선은 빨강 8번 · 노랑 9번 · 초록 10번입니다.

확인이 남은 내용

  • 부저의 정확한 모델·능동/수동 종류·정격
  • 최종 15초 악보 코드의 실제 보드 연주
  • 신호등 모듈의 공통 전원 단자 사양

부저 시험 결과와 최종 코드의 업로드 성공 여부는 대화에서 확인되지 않았습니다.

처음에는 빨간불 대기·초록불 점등 방식으로 시작했고, 마지막에는 초록불 대기 / 빨간불 15초 연주로 변경했습니다. 이 문서는 책상 위 교육용 모형의 실습 기록입니다.

02 / 준비와 배선

색상보다 핀 번호와 단자 글자를 먼저 확인

준비물: UNO, USB 케이블, 3색 신호등 모듈, 푸시 버튼, 2핀 부저, 브레드보드, 점퍼선. 수동 피에조 부저 연결 예시에는 1kΩ 저항 1개를 사용합니다.

아두이노 핀연결 대상메모
D8R · 빨간불HIGH 켜짐 / LOW 꺼짐
D9Y · 노란불HIGH 켜짐 / LOW 꺼짐
D10G · 초록불G는 초록색 신호 단자이며 GND가 아닙니다.
D2버튼 한 접점다른 접점은 GND / INPUT_PULLUP
D111kΩ 저항 → 부저 +소형 수동 피에조 부저를 가정한 예시
GND버튼 다른 접점 / 부저 −브레드보드 − 레일을 통해 공유
모듈 공통 단자실제 제품 사양에 따라 연결이 문서만 보고 V → 5V로 결정하지 않습니다.

선이 겹치지 않는 연결도

이전 안내의 정정: 처음 받은 그림은 V·GND 표시가 서로 맞지 않았고, 생성된 배선 사진에도 핀 위치 오류가 있었습니다. 실제 실습에서는 HIGH 점등을 확인했습니다. 현재 정상 동작하는 모듈 전원 배선은 유지하고, 처음부터 배선할 때는 제품 사양을 확인하세요. 이 연결도에서는 미확인 공통 전원선을 생략했습니다.

사용자는 신호등 키트에 외부 저항이 필요 없다고 알려주었습니다. 따라서 이 실습에서는 LED 신호선에 외부 저항을 추가하지 않는 구성을 기록합니다. 저항 내장 여부는 사진으로 확인되지 않았으므로 다른 모듈에 그대로 적용하지 마세요.

03 / 버튼 입력과 접지

버튼을 누르면 LOW가 되는 이유

pinMode(button, INPUT_PULLUP)은 내부 풀업 저항을 사용하는 설정입니다.

버튼 상태입력값
놓았을 때HIGH
눌렀을 때LOW · D2가 GND에 연결됨

버튼용 외부 풀업 저항은 필요 없습니다. 30ms 기다린 뒤 다시 읽어 접점 흔들림으로 인한 오작동을 줄입니다.

4핀 버튼 연결

  • 눌렀을 때 연결되는 서로 다른 두 접점을 사용합니다.
  • 일반적인 4핀 택트 버튼은 대각선 두 다리로 연결할 수 있습니다.
  • 같은 접점의 두 다리는 평소에도 연결되어 있으므로 피합니다.
  • 브레드보드 중앙 홈을 가로질러 꽂고 두 접점이 같은 연결 행에 묶이지 않게 합니다.
  • 보드의 RESET 버튼은 이번 입력 버튼이 아닙니다.

GND 구멍이 부족할 때

아두이노 GND ── 브레드보드 − 레일
                          ├── 버튼의 GND 쪽 접점
                          └── 부저의 − 단자

한 구멍에 여러 선을 억지로 넣지 않고, 전기적으로 이어진 레일의 서로 다른 구멍에 꽂습니다. 레일은 중앙에서 끊어져 있거나 좌우가 분리될 수 있으니 필요한 구간은 점퍼선으로 연결합니다. 파란색 표시 자체가 접지를 만드는 것은 아니며 UNO의 GND와 연결해야 합니다.

최종 코드는 동작 중 추가 입력을 무시합니다. 버튼을 계속 누르고 있어도 한 번만 실행하고, 놓은 상태가 30ms 유지되어야 다음 입력을 받을 수 있습니다.
04 / 소리 만들기

부저는 음의 주파수와 길이로 연주합니다

사진에서 확인한 부품은 위에 구멍이 있는 검은 원통형의 2핀 부저입니다. 외형만으로 능동·수동 종류는 확정하지 않았습니다. 아래 연주 코드는 수동 피에조 부저 기준입니다.

연결

D11 → 1kΩ 저항 → 부저 +
부저 − → GND

1kΩ은 부저 선에 직렬로 넣는 전류 제한용 예시입니다. 모든 부저의 정격을 대신하는 값은 아니며 소리가 작아질 수 있습니다. 극성은 실제 + 표시나 제품 자료를 확인하세요.

핵심 함수

tone(11, 1000) : 1000Hz 출력
tone(11, 440, 500) : 440Hz를 500ms 출력
noTone(11) : 소리 끄기

Hz는 음의 높이, ms는 시간을 나타냅니다. 1000ms = 1초입니다.

수동 부저는 여러 높이의 음을 만들 수 있습니다. 능동 부저는 자체 발진 회로가 있어 같은 코드로 멜로디가 제대로 나오지 않을 수 있습니다. 종류와 정격이 다르면 구동 방법도 달라집니다.

부저 단독 테스트 코드

const int buzzer = 11;
void setup() {
  pinMode(buzzer, OUTPUT);
}
void loop() {
  tone(buzzer, 1000);
  delay(1000);
  noTone(buzzer);
  digitalWrite(buzzer, LOW);
  delay(1000);
}

1초 소리 → 1초 무음이 반복되는지 확인합니다. 이 코드는 기존 신호등 프로그램을 대체하므로 시험 후 최종 코드를 다시 업로드하세요.

05 / 문제 해결 기록

현상을 보고 원인을 좁혀가기

관찰한 현상확인·수정한 내용배운 점
LOW 코드에서 불이 안 켜짐HIGH/LOW 반복 시험 후 HIGH 고정 시험으로 세 LED 점등 확인부품의 점등 논리를 먼저 확인
노랑 대기 → 초록 1초 → 빨강 5초당시 실제 배선은 8=노랑, 9=초록, 10=빨강. 핀 설정을 맞추자 정상 동작코드의 이름과 실제 색이 맞아야 함
배선을 빨강 8·노랑 9·초록 10으로 변경red=8, yellow=9, green=10으로 코드도 복원배선과 코드를 함께 확인
버튼을 누르면 빨간불만 꺼짐버튼 입력은 인식되는 단서. LED 배선·점등 방식을 따로 검사입력 문제와 출력 문제를 구분
GND 구멍 부족브레드보드 − 레일을 GND에 연결해 공유여러 부품이 공통 접지 사용 가능
코드 오류 발생구체적인 오류 메시지는 받지 못함. 단순 코드와 복사 문자 점검 안내오류 원인은 확정하지 않고 메시지로 확인
복사 문자 점검: 대화에 &#x20;이나 INPUT\_PULLUP이 섞인 적이 있습니다. 전자는 지우고 후자는 INPUT_PULLUP으로 고칩니다. 이 문서의 복사 버튼과 코드 다운로드에는 해당 문자가 없습니다.

세 LED를 모두 켜는 테스트 코드

void setup() {
  pinMode(8, OUTPUT);
  pinMode(9, OUTPUT);
  pinMode(10, OUTPUT);
  digitalWrite(8, HIGH);
  digitalWrite(9, HIGH);
  digitalWrite(10, HIGH);
}
void loop() {}
06 / 최종 코드

초록 대기 · 빨강 15초 멜로디

실제 보드 검증 전

사용자가 제공한 「인생의 회전목마」 악보 이미지의 첫째·둘째 줄을 보고 옮긴 발췌입니다. 전체 악보는 포함하지 않으며 앞부분만 반복하지 않고 뒤 구간까지 한 번 이어서 연주합니다. 사진 판독에 따른 음과 길이의 오차는 실제 연주로 확인해야 합니다.

발췌 구간을 15초로 압축해 원래 악보보다 빠르게 연주합니다. 15000UL을 더 큰 값으로 바꾸면 빨간불과 연주 시간이 함께 길어집니다. 마지막 음 이후 소리를 끄고 노란불로 바뀝니다.
// 2026-10-23 버튼 신호등 + 멜로디 부저
// LED HIGH 점등 / INPUT_PULLUP / 수동 피에조 부저 기준
const int red = 8;
const int yellow = 9;
const int green = 10;
const int button = 2;
const int buzzer = 11;

// 제공된 악보 첫째·둘째 줄의 발췌. 0은 쉼표.
// 사진 판독으로 옮긴 음이며 실제 연주 확인 전입니다.
const int notes[] = {
  294, 392, 466, 587, 587, 523, 466, 440, 466,
  0, 392, 466, 587, 784, 784, 784, 698, 622, 698,
  0, 440, 587, 698, 880, 784, 698, 659, 698,
  784, 698, 659, 587, 523, 466, 523, 587, 523, 392, 440
};

// 길이 비율: 1=8분음표, 2=4분음표. 붙임줄은 합산.
const int lengths[] = {
  2, 2, 2, 4, 2, 2, 2, 2, 6,
  3, 1, 1, 1, 4, 2, 2, 2, 2, 6,
  3, 1, 1, 1, 4, 2, 2, 2, 2,
  4, 2, 4, 2, 2, 2, 2, 2, 2, 2, 12
};
const int noteCount = sizeof(notes) / sizeof(notes[0]);

void light(int pin)
{
  digitalWrite(red, LOW);
  digitalWrite(yellow, LOW);
  digitalWrite(green, LOW);
  digitalWrite(pin, HIGH);
}

void playMusic()
{
  int totalUnits = 0;
  for (int i = 0; i < noteCount; i++) {
    totalUnits += lengths[i];
  }

  unsigned long startedAt = millis();
  int playedUnits = 0;

  for (int i = 0; i < noteCount; i++) {
    playedUnits += lengths[i];
    unsigned long endTime = 15000UL * playedUnits / totalUnits;
    unsigned long elapsed = millis() - startedAt;
    if (elapsed >= endTime) continue;

    unsigned long duration = endTime - elapsed;
    if (notes[i] == 0) {
      noTone(buzzer);
    } else {
      tone(buzzer, notes[i], duration * 95UL / 100UL);
    }

    while (millis() - startedAt < endTime) {
      delay(1);
    }
    noTone(buzzer);
  }
  digitalWrite(buzzer, LOW);
}

void setup()
{
  pinMode(red, OUTPUT);
  pinMode(yellow, OUTPUT);
  pinMode(green, OUTPUT);
  pinMode(button, INPUT_PULLUP);
  pinMode(buzzer, OUTPUT);
  digitalWrite(buzzer, LOW);
  light(green);
}

void loop()
{
  if (digitalRead(button) != LOW) return;
  delay(30);
  if (digitalRead(button) != LOW) return;

  light(yellow);
  delay(1000);
  light(red);
  playMusic();
  light(yellow);
  delay(1000);
  light(green);

  // 버튼을 놓은 상태가 30ms 유지되어야 다시 작동
  unsigned long releasedAt = millis();
  while (millis() - releasedAt < 30) {
    if (digitalRead(button) == LOW) releasedAt = millis();
  }
}

코드 읽는 순서

  1. 핀 설정: LED 8·9·10, 버튼 2, 부저 11 지정
  2. light(): 모두 끈 뒤 선택한 LED 하나만 켜기
  3. playMusic(): 음 길이의 비율을 유지하면서 전체를 15초에 배분
  4. setup(): 핀 모드 설정 후 초록불로 대기
  5. loop(): 버튼 → 노랑 → 빨강·연주 → 노랑 → 초록
  6. 해제 확인: 버튼을 누른 채로 있을 때 자동 반복 방지

설명을 쉽게 하기 위해 delay()와 대기 반복문을 사용합니다. 다른 입력을 동시에 처리해야 한다면 millis() 기반 상태 제어로 확장할 수 있습니다.

07 / 실습 점검

연결 → 개별 시험 → 전체 동작 확인

  1. USB 전원을 빼고 배선합니다. 핀 번호, 모듈 전원 사양, 부저 극성을 확인합니다.
  2. LED 단독 시험: HIGH 고정 코드로 세 색의 점등을 확인합니다.
  3. 버튼 확인: 누르면 D2와 GND가 연결되는지 확인합니다.
  4. 부저 단독 시험: 1초 소리 / 1초 무음 코드를 올립니다.
  5. 최종 코드 업로드: IDE의 기존 코드를 모두 지우고 붙여 넣습니다. 보드와 포트를 선택하고 확인(컴파일), 업로드를 실행합니다.
  6. 전체 순서 확인: 초록 대기 → 노랑 1초 → 빨강 15초·연주 → 노랑 1초 → 초록 복귀.
  7. 누르고 있기 시험: 버튼을 놓기 전에는 다시 실행되지 않는지 확인합니다.

컴파일 오류가 나면

exit status 1 위의 구체적인 오류 문장을 확인합니다. setup()/loop() 중복과 복사 특수문자를 점검하세요.

업로드가 안 되면

보드·포트 선택과 USB 케이블을 확인합니다. 업로드 실패와 컴파일 오류는 구분해서 기록합니다.
